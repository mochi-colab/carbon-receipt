# 탄소영수증 시범 구현 (초기 개발 범위)

청록수소(메탄 열분해) 실험 기록을 표준 Excel 양식으로 받아 **단위 환산·입력 검사 → 수소 1 kg당 배출량 계산 →
배출원별 기여도와 탄소영수증 출력**까지 수행한다.

> **가상 데이터·예시 배출계수 기반.** 양식의 실험값(EXP-800)은 가상 예시이고, 배출계수는 시연용 예시값이다(공식 계수 아님).
> 결과는 실험실 규모 연구용이며 정제·압축을 제외한 값으로, 상업 규모 추정치가 아니다.

## 보고서 첨부 자료 위치

2026학년도 2차 Meta-BTS 최종 결과보고서(팀 탄소영수증)의 첨부 1~5는 이 저장소의 다음 위치에 있다.

| 첨부 | 내용 | 위치 |
|---|---|---|
| 첨부 1 | 표준 입력양식(실험기록, 계산설정, 배출계수, 작성예시 시트) | `탄소영수증_입력양식.xlsx` |
| 첨부 2 | 시범 구현 코드와 README | `*.py`, 이 문서 |
| 첨부 3 | 검증 결과(사례 입력, 결과표, 수작업 대조표, 탐지평가 판정표, 반례 점검표, 영수증) | `검증사례/`, `결과/`, `반례_수정전_기록.csv` |
| 첨부 4 | 정상 사례의 Excel 수식 계산 | `수작업기준.xlsx` |
| 첨부 5 | 공개 논문 6편 대조표와 보고율, 대표 예시의 입력 파일과 영수증 | `결과/공개논문6편/`, `결과/논문적용/` |

## 설치

Python 3.10 이상. 엔진 버전 v0.3(수정 전 반례 기록 `반례_수정전_기록.csv`는 v0.2 결과).

```
pip install openpyxl matplotlib
```

영수증 그림의 한글 표시는 Noto Sans CJK, 나눔고딕, 맑은 고딕, AppleGothic 중 설치된 글꼴을 사용한다.

## 실행

```
python carbon_receipt.py 탄소영수증_입력양식.xlsx -o 출력
```

입력 파일의 '실험기록' 시트에 실험ID가 입력된 행을 실험별로 처리한다(빈 양식이면 '실험ID가 입력된 행이 없음'을 알린다).
작성예시를 그대로 계산해 보려면 `python carbon_receipt.py 검증사례/사례1_정상.xlsx -o 출력` 을 실행한다.

검증 6사례 자동 확인(사례 파일 생성 → 계산 → 예상 처리와 비교 → 수작업 비교 → 탐지 평가):

```
python run_validation.py
```

모두 예상대로 처리되면 종료코드 0, 하나라도 다르면 1을 반환한다.

연구자가 원자료를 확인한 뒤 값을 고칠 때(원본은 두고 수정본 + '수정이력' 시트 생성):

```
python correct_record.py 원본.xlsx 수정본.xlsx --exp EXP-800 --seg 반응 --code ELEC --value 5000 --unit Wh --reason "원본 로그 대조: 단위 오기" --by 연구자
```

연구자가 원자료를 대조해 '범위 밖이지만 맞는 값'이라고 확인한 경우(현재 허용 검사: 전력 원단위 이상치):

```
python correct_record.py --ack 원본.xlsx 확인본.xlsx --exp EXP-800 --check "전력 원단위 이상치" --note "원본 로그 대조, 값 맞음" --by 연구자
```

확인 표시는 '검토확인' 시트에 확인 당시 원단위 계산 입력값(구간별 전력, 수소 생산량)과 함께 남는다. 경고는 영수증에 그대로 남고 계산은 진행된다.
재실행 때 그 입력값 중 하나라도 다르면 확인 표시는 무효가 되어 다시 보류된다(⑧-2: 원단위가 같아도 구간별 값이 바뀌면 무효). 필수값 누락·중복 기록·단위 미인식은 확인 표시로 넘어갈 수 없다.

공개 논문 기록 적용(Al-Fatesh 외 2016, Catalysts 6, 40): `python make_paper_case.py` → `결과/논문적용/`

## 검사 항목과 계산 처리

| 검사 | 문제 시 상태 | 계산 처리 (계산설정의 규칙 행) |
|---|---|---|
| 필수값(공란 + 계산설정 REQUIRED_ROWS의 행 존재) | 자료 부족 + 필요한 항목·측정 구간 안내 | 보류 (RULE_MISSING) |
| 중복 기록(같은 실험ID·구간·항목 2행 이상) | 확인 필요, 자동 삭제 안 함 | 보류 (RULE_DUPLICATE) |
| 단위 인식(환산표·표준단위 대조) | 확인 필요 | 보류 (RULE_UNIT_UNKNOWN) |
| 값 범위·물리 한계(유한수(nan·inf 아님), 음수 소비량, 몰분율·온도 범위, 정수 사용 횟수, 0보다 커야 하는 운전시간, 몰분율 합, 투입보다 많은 미반응 메탄, 수소에 비해 부족한 메탄 신규 공급량, 등록되지 않은 구간·항목코드) | 확인 필요 | 보류 (RULE_RANGE) |
| 배출계수 매칭(적용 버전·항목코드) | 자료 부족 | 보류 (RULE_EF_MISSING) |
| 배출계수 단위·값·중복(계수 단위 분모 = 활동량 표준단위, 유한수(nan·inf·문자 아님), 음수 계수, 같은 버전 중복) | 확인 필요, 자동 환산하지 않음 | 보류 (RULE_EF_INVALID) |
| 수소 생산량(기능단위) | 0 이하이면 계산 불가 + 사유 | 계산 불가 (RULE_H2_NONPOSITIVE) |
| 전력 원단위 이상치(단위 오기 의심) | 범위 밖이면 확인 필요 | 보류 (RULE_ELEC_OUTLIER) |
| 화학양론 일관성(H·C) | 허용범위 밖이면 확인 필요 + 가능 원인 | 계산 수행, 경고 표시 (RULE_STOICH) |

다른 검사의 문제 때문에 판정할 수 없는 검사는 '판정 보류'(중복·단위 문제) 또는 '자료 부족'(값 없음)으로 표시한다.
규칙 설정과 무관하게, 계산에 쓰는 값이 하나라도 확정되지 않으면 계산하지 않는다.

계산: 배치 전체(승온+반응+중단) 기준이 기본, 반응 구간만은 참고값. 부산물 공제 없음이 기본, 질량 배분은 고체탄소
회수량이 있을 때만 참고값으로 산출한다.

## 이 시범 구현에 포함하지 않은 것

- 실험 간 순위 비교, 비교 조건 점검, 인증 기준선 비교, 다수 실험 추세 시각화
- 에너지 기록 범위 점검(전력 측정 구간과 수소 집계 구간 대조), 유사 조건 과거 자료 기반 이상치 검사
  (현재 전력 이상치 범위는 계산설정의 예시값)
- AI 입력 보조·배출계수 추천, 기존 LCA 도구(Brightway·openLCA) 연계
- 실제 연구자 확인 절차: 사례 ②의 수정은 테스트 스크립트가 `correct_record.py`로 모사한다
